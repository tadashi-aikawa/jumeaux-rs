# Jumeaux

Jumeauxは、2つのAPIレスポンスの差分を確認するCLIツールです。

<img src="img/logo-large.png" alt="Jumeaux" width="480" />

リクエスト一覧を2つのエンドポイントへ送り、レスポンスの差分をレポートとViewerで確認できます。

このサイトはRust版のドキュメントです。バージョンは `0.1.0` から始まります。
