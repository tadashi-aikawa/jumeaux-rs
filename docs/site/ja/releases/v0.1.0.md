# v0.1.0

Rust版の最初のリリースです。
公開済みのバイナリと公開日は [GitHub Releases](https://github.com/tadashi-aikawa/jumeaux-rs/releases/tag/v0.1.0) で確認できます。

- Python版7.0.0を基準に、CLIと組み込みアドオンをRustで実装しました。
- macOSとLinux向けのバイナリ配布に対応しました。
    - アーキテクチャ: arm64とx86_64。
- `final/miroir` をRust版でも利用できるようにしました。
    - ビルド: Cargo feature `miroir` は既定で有効です。配布バイナリにも含まれます。
    - 無効時: `--no-default-features` のビルドでは `final/miroir` の設定がエラーになります。
    - 詳細: [Miroir](../addons/final.md#miroir)
- Python版との差異と移行手順を整備しました。
    - 詳細: [Python版からの移行](../getstarted/migration.md)
- カスタムアドオンとPython transformerの代替は準備中です。
    - 詳細: [カスタムアドオン](../addons/custom.md)
